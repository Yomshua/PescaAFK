#  **PescaAFK 1.8.8**

Pesca AFK é um plugin desenvolvido por mim, Daymon, como um sistema interativo e legal de se usar.

## Comandos :
  - /pesca iniciar - Incia a pesca AFK (porém apenas se o player estiver pescando!).
  - /pesca parar - Desativa a pesca e o player recebe os peixes na sua gui.
  - /pesca menu - Abre o menu, com o top player e a mochila com os peixes.
